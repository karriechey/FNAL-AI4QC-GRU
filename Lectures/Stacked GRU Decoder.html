Stacked GRU Decoder

FNAL AI4QC · GRU decoder

How a stacked GRU decodes the surface code

A single-layer GRU updates one memory per QEC round. A stacked GRU adds a second recurrent layer that reads the first layer's memory instead of the raw syndrome. Same rounds, more computation per round.

Single-layer GRU

Each round, one GRU cell reads that round's detector events (80 bits at d=9) and updates a 280-dimensional hidden state. After the last round, a small head reads the final state and outputs the probability of a logical flip.

h¹ₜ = GRU₁(xₜ, h¹ₜ₋₁) · output = head(h¹₉)

Two-layer stacked GRU (f2280)

Layer 1 is unchanged, except that it now passes its hidden state up at every round instead of only at the end. Layer 2 is a second GRU with its own weights and its own 280-dim memory. It never sees the detectors directly: its input at round t is h¹ₜ, layer 1's running summary. The head reads only layer 2's final state. f3280 adds a third layer on top in the same way.

h¹ₜ = GRU₁(xₜ, h¹ₜ₋₁) · h²ₜ = GRU₂(h¹ₜ, h²ₜ₋₁) · output = head(h²₉)

How is stacked different than one layer

What it adds is depth per round. Each round gets two (or three) nonlinear processing steps instead of one, and each layer keeps its own memory. The extra computation happens within a time step, not across more time steps.

On held-out shots, the stack wins with fewer parameters: 0.717× vs 0.793× MWPM, with 27% fewer parameters, so the win can't come from capacity.

On its own training data, the wide model is better: 0.543× vs 0.580×. The wide model can represent the decoding function; it memorises the fixed pool and generalises worse. In this pair, the advantage of depth is generalisation, not raw expressiveness.

Why depth could generalise better.

  1. (What the data shows) A better inductive bias. A wide single layer has enough freedom to fit the training pool shot by shot. A stack has to route everything through layer 1's summary, which pushes it toward reusable features instead of memorised patterns.
  2. (Hypothesis) Twice the nonlinear stages per round. A GRU cell already has several nonlinearities (sigmoid gates feeding a tanh). Stacking puts a second full cell on the path from xₜ to the output, so the model can build features of features. Two purely linear layers would collapse into one, W₂(W₁x) = (W₂W₁)x; the gates and tanh stop that.
  3. (Hypothesis) The target suits composition. The logical flip is a high-degree parity of detection events. Building it from local pieces, then combining them, matches the structure of the problem; a solution assembled that way is more likely to carry over to new shots than one fitted in a single wide step.
  4. (Hypothesis) Two memories with their own jobs. Each layer keeps its own recurrent state: layer 1 can follow how the detector pattern changes round to round, and layer 2 can accumulate that into evidence about the logical. This fits Gabe's suggestion that the stack makes better use of space-time structure.

One analyst

u560: one analyst with a very large memory reads the raw syndrome each round. Big enough to remember every case seen in training, which is exactly the risk.

Two analysts in series

2×u280: the first reports the patterns it sees; the second reasons over that report. Smaller memories each, but a two-stage pipeline that has to summarise as it goes.

To test the mechanism:

  • Timescale per layer: how much each layer's state changes from round to round. A slower upper layer means it integrates over longer time.
  • Where the gains are: whether the stack's wins concentrate in shots with many time-like or space-time matches.
  • Linear probe per layer: how well each layer's final state predicts the flip. Rising accuracy with depth means each layer makes the answer easier to read off.

Why depth helps a decoder: the intuition

These are working hypotheses that fit our results. We haven't probed the hidden states to confirm what each layer actually encodes.

Layer 1: local events

Reads raw detector flips each round. Well placed to pick up local patterns: which detectors fired, pairs that point to one data-qubit error, and the same detector flipping in consecutive rounds, which signals a measurement error.

Layer 2: chains and the boundary

Reads layer 1's summaries instead of raw bits. Well placed to track how defects link into error chains across space and time, and whether the accumulated correction crosses the logical boundary, which is the question the head answers.

  1. The answer is a high-degree parity. Whether a logical flip happened depends on the combined parity of many error events spread over the patch and over rounds. A network builds such functions most efficiently by composition: parities of local parities. Depth gives it that composition; a single layer has to produce it with one nonlinear update per round.
  2. It mirrors how matching works. MWPM first pairs up nearby defects, which is a local step, then checks whether the pairing crosses the boundary, which is a global step. Layer 1 and layer 2 can split the work the same way.
  3. Each layer keeps its own memory. Layer 2's memory tracks the state of the chains, already cleaned up by layer 1, rather than raw events. That gives the decoder a second, more abstract timescale.
  4. Why d=9 needs it more than d=7? d=9 has 80 detectors per round instead of 48, and longer error chains.
